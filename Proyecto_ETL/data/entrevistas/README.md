# Entrada cualitativa pendiente

Cuando estén disponibles las entrevistas, coloque aquí las transcripciones en
texto (`.txt`, `.docx` o `.csv`) y conserve un identificador anónimo para cada
participante.

Para la matriz inicial se recomienda registrar, como mínimo:

- `participant_id`
- `role_or_profile`
- `interview_date`
- `segment_id`
- `transcript_text`
- `source_file`

El análisis debe seguir el `Prompt_Analisis_Cualitativo.pdf`: codificación
abierta, codificación axial, categorías/temas, descripción densa, verbatims y
conclusiones. Después se incorporará la evidencia cualitativa a la matriz de
triangulación con V1, V2–V4/NPS y RD.
